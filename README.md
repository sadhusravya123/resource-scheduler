
##Resource Scheduler

## Aim
To develop a React application for scheduling and allocating resources.

## Technologies Used
- React
- JavaScript
- HTML
- CSS

## Description
The Resource Scheduler allows users to manage resources and schedule them for different tasks or activities.

## Features
- Add resource details
- Schedule resources
- Allocate resources
- Display schedules
- Dynamic UI using React

npm install
